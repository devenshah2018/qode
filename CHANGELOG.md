# Changelog

## 1.0.0 — release candidate

- Replace execution-during-parsing with source-aware compilation and an isolated C11 statevector runtime.
- Correct complex amplitudes, interference, state preservation, and entanglement.
- Complete the original gate backlog and add rotations, measurement/collapse, reset, classical conditions, seeded sampling, and explicit inspection.
- Introduce `qode check`, `run`, and `sample`, standard input, versioned JSON, typed errors, and an embedding API.
- Add the React/CodeMirror/WebAssembly playground with deterministic backward stepping, mixed-state Bloch vectors, guided examples, local persistence, and portable exports.
- Add numerical, allocation, browser, parity, sanitizer, fuzzing, benchmark, and clean-build workflows.
- Remove generated binaries from source tracking and document the incompatible syntax migration.

No hosted release is implied by this candidate entry.
